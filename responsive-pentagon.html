🎯 How This Responsive Layout Works

1. Square Container with Aspect Ratio

.pentagon-wrapper {
  width: 100%;              /* Full width of parent */
  max-width: 600px;         /* Maximum size */
  padding-bottom: 100%;     /* Creates 1:1 aspect ratio */
  position: relative;
}

The padding-bottom: 100% trick creates a perfect square that scales responsively.

2. Percentage-Based Positioning

Instead of: translate(200px, -62px)
Use: translate(40%, -12.4%)

Calculation: (pixel value / container size) × 100
Example: 200px / 500px container = 40% 
/* Item positions using percentages */
.pentagon-item:nth-child(2) {
  /* Top: 0°, radius = 40% */
  transform: translate(-50%, -50%) translate(0%, -40%);
}

.pentagon-item:nth-child(3) {
  /* 72°: radius = 40% */
  transform: translate(-50%, -50%) translate(38%, -12.4%);
}

/* etc... */

3. Fluid Typography with clamp()

font-size: clamp(12px, 2vw, 16px);
/*              min   ideal  max   */

Text scales smoothly between min and max based on viewport width.

4. Dynamic Item Sizing

.pentagon-item {
  width: 22%;              /* Scales with container */
  min-width: 90px;         /* Never too small */
  max-width: 140px;        /* Never too large */
}

5. Breakpoint Adjustments

/* Tablet (≤768px) */
@media (max-width: 768px) {
  .pentagon-wrapper {
    max-width: 500px;
  }
  .pentagon-item {
    width: 25%;            /* Slightly larger % */
  }
}

/* Mobile (≤480px) */
@media (max-width: 480px) {
  .pentagon-wrapper {
    max-width: 350px;
  }
  .pentagon-item {
    width: 28%;            /* Even larger % */
  }
}

🔧 Webflow Implementation

Step 1: Create Responsive Container

  • Main wrapper: width: 100%, max-width: 600px
  • Add a child div: padding-bottom: 100% (creates square)
  • Add another child: position: absolute, top: 0, fill container

Step 2: Use Percentage Transforms

  • Item 1: translate(-50%, -50%) translate(0%, -40%)
  • Item 2: translate(-50%, -50%) translate(38%, -12.4%)
  • Item 3: translate(-50%, -50%) translate(23.5%, 32.4%)
  • Item 4: translate(-50%, -50%) translate(-23.5%, 32.4%)
  • Item 5: translate(-50%, -50%) translate(-38%, -12.4%)

Step 3: Set Breakpoints in Webflow

  1. Desktop (base): 600px max-width, items 22% width
  2. Tablet breakpoint: 500px max-width, items 25% width
  3. Mobile L: 400px max-width, items 27% width
  4. Mobile P: 350px max-width, items 28% width

Step 4: Container Width Strategies

Option A: Max-width approach (used here)

width: 100%;
max-width: 600px;
margin: 0 auto;

Option B: Percentage of screen

width: 80vw;        /* 80% of viewport */
max-width: 600px;
min-width: 300px;

Option C: Container-relative

width: 100%;        /* Fills parent container */
max-width: 100%;    /* Never overflow */

🧮 Calculate Your Own Percentage Positions

Open browser console and run:

function calcPercentagePositions(items, radiusPercent) {
  for (let i = 0; i < items; i++) {
    const angle = (-90 + (360 / items) * i) * (Math.PI / 180);
    const x = (radiusPercent * Math.cos(angle)).toFixed(1);
    const y = (radiusPercent * Math.sin(angle)).toFixed(1);
    console.log(`Item ${i + 1}: translate(-50%, -50%) translate(${x}%, ${y}%)`);
  }
}

// Calculate for 5 items with 40% radius
calcPercentagePositions(5, 40);
