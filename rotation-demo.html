🎨 Vivus SVG Animation + Rotation Demo

Demo 1: Single SVG with Rotation Controls

Click the buttons to rotate the SVG to different angles. Notice how it always takes the shortest path (270° to 10° goes via 0°, not backwards).

Try going from 270° to 10° - it rotates efficiently!

Demo 2: Multiple SVGs with Independent Rotation

Each SVG can be rotated independently. The angles normalize automatically (e.g., 720° becomes 0°, 450° becomes 90°).

Note: IDs must contain angle numbers (with or without "deg")

Demo 3: Testing Edge Cases

Test angles over 360° - they normalize automatically. 720° = 0°, 450° = 90°, etc.

Open console (debug=true) to see rotation calculations

Demo 4: Using Links (not just buttons)

Works with any clickable element, including links with data-rotate-target attribute.

Reset 120° 240°

Demo 5: Scroll-Triggered + Rotation

SVGs still animate on scroll as normal, then can be rotated after drawing.

Scroll up/down to see the original animation trigger
